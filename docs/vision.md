# Vision

Make psytrance in the browser, by clicking or by asking.

- **Simple first.** A tracker you understand by looking at it: tracks, steps, sections. Every
  control visible and labelled; undo instead of confirmations.
- **AI-native.** The song is a readable, validated JSON file, so an AI can write a whole track,
  rework a section, or vary a pattern, and the result is something you can then edit by hand.
- **Three ways to make sound**: a drum machine, synths (bass, acid, pads, leads) and a sampler.
  The defaults sound like psytrance out of the box.
- **Bring material in**: MIDI files today; tracker modules and video game music formats next,
  so a game soundtrack can become the seed of a track.
- **Free to run**: a static site on Cloudflare Pages, audio in the browser, no accounts.

## Not now
Recording audio, mixing/mastering depth (sends, automation), collaboration, a full DAW timeline.
